# B站精准搜索

一个运行在 `search.bilibili.com` 的 Tampermonkey 用户脚本。它保留 B站原生页面，并增加独立的“🎯 精准搜索”面板：先用统一的关键词相关性门槛排除跑题内容，再在相近相关性的结果中选择“长期质量 / 增长趋势 / 最新热播”排序。

## 核心流程

```text
关键词
  → 综合 / 播放 / 最新 / 收藏 / 弹幕多路召回
  → 仅保留视频并按 BV 号去重
  → 标题 / 标签 / 简介 / UP主 / 分区相关性评分
  → 统一相关性硬门槛与相关性分档
  → 补全统计；为部分候选采样当前在线人数
  → 读取本地历史快照，区分真实增速与低置信度估算
  → 在相关性分档内按所选视图重排
```

- 默认匿名调用 B站接口，不携带登录 Cookie，尽量降低观看画像进入候选池的可能。
- 支持完整短语（`"澳网 决赛"`）和排除词（`-德约科维奇`）。
- 数字、年份、型号和版本词必须在核心字段精确命中；质量、增长或热度不能挽救错误型号。
- 每张卡同时显示相关、质量、增长、时效、数据完整度，以及命中和扣分说明。
- 精准面板使用独立 Shadow DOM；原生结果不会被删除或重建，关闭面板即可原样返回。
- 所有 B站端点、响应清洗、缓存和风控识别集中在 `src/api-adapter.js`，接口变化不会散落到评分和界面代码中。

## 一套准入，三种排序

三个标签共享同一个候选池和同一套相关性准入规则，切换标签不会重新搜索。查询越短，准入越严格：单词查询要求完整覆盖；两词与多词查询分别使用适合长尾检索的相关性、覆盖率门槛。通过后仍先按 5 分宽的相关性区间分档，下一档的视频不能只靠数据指标反超上一档。

| 排序 | 档内组合 | 主要含义 |
|---|---|---|
| 长期质量 | 40% 相关性 + 60% 质量 | 看累计影响力与平滑后的深度互动；发布时间完全不参与质量分 |
| 增长趋势 | 35% 相关性 + 55% 增长 + 10% 质量 | 优先本地两次采样之间的真实增量；历史不足时显示“估算”或“积累中” |
| 最新热播 | 35% 相关性 + 55% 时效 + 10% 质量 | 综合发布时间和当前观看人数；质量只作小幅校正 |

### 长期质量

长期质量由累计播放、收藏、投币、分享、点赞、评论和弹幕构成。累计指标先做对数压缩，互动率使用平滑处理，避免小样本的偶然高比例被放大。发布时间、视频年龄、发布后平均速度以及“新视频加分”均不属于质量分。

### 增长趋势

脚本会在本地限量保存指标快照。两次有效采样间隔足够时，增长分根据各项指标的实际增量和时间跨度计算，并标为“真实增速”；只有当前累计数据时，只能给出低置信度的平均增速估算；连估算条件都不足时显示“积累中”。首次使用后过一段时间再次搜索，增长判断才会逐步变得可靠。

### 最新热播

时效分以发布时间和当前在线观看人数为主，并少量参考长期质量。在线人数接口是瞬时、近似、分 P 级数据，脚本只对较小的候选集节制采样，并明确显示是否采样成功；缺失时会降级为发布时间等可用信息，不会把缺失当成零。

## 已知边界

- 脚本只能重排 B站接口已经召回的候选，无法发现完全未被官方搜索召回的视频。
- 相关性是本地字面匹配，不是大模型语义检索；别名、隐喻和完全不同写法仍可能需要补充关键词。
- 增长趋势需要时间跨度；新安装或首次见到某个 BV 号时，不可能获得真实增速。
- B站搜索结果不总是携带完整统计，详情与在线接口也没有公开稳定性承诺。脚本会按可用字段重新归一化并显示完整度。
- 一次完整的缓存未命中搜索最多会读取 15 路候选页、补全 60 条详情并采样 24 条在线数据；脚本已限制并发、加入间隔并缓存结果，但仍不建议连续快速刷新大量不同关键词。
- B站可能调整接口或触发访问验证。脚本遇到风控状态会立即停止本轮请求，不会换端点绕过；稍后重试即可，原生搜索始终可用。

## 开发与验证

要求 Node.js 20 或更新版本：

```powershell
npm install
npm run verify
```

`npm run verify` 会做语法检查、运行测试、构建单文件 userscript，并再次检查构建产物语法。详细结果见 `TEST_REPORT.md`。

## 项目结构

```text
src/api-adapter.js     B站接口、统计补全、在线采样、缓存与风控
src/text.js            查询解析和文本匹配基础
src/scoring.js         统一相关性门槛、质量/增长/时效评分与重排
src/metric-history.js  本地指标快照、限量保留与过期清理
src/ui.js              独立精准面板、解释卡片与分页
src/main.js            页面生命周期、数据流水线、SPA 同步和取消
dist/                  可直接安装的单文件脚本
test/                  自动化测试
```
